# ドレミ耳トレ

相対音感を鍛える、超初心者向けのブラウザアプリ。`index.html` をブラウザで開くだけで動きます（インストール不要）。

## レベル
- **Lv.1 上がる？下がる？** — 2音を聴いて、2つめが高いか低いか。音の離れ具合（ド→高いド／ラ／ソ／ファ／ミ／レ、まぜる）を固定して選べる
- **Lv.2 ド・ミ・ソ** — 「ド」を聴いたあと、次の音がド/ミ/ソ/高いドのどれか
- **Lv.3 ド〜ソ** — ドレミファソの5音
- **Lv.4 ドレミ全部** — ドレミファソラシドの8音

問題ごとにキー（ドの高さ）が変わるので、絶対的な音の高さではなく「ドからの距離」で聴き分ける練習になります。

## 操作
- Space: もう一度聴く / 1〜8: 回答 / Enter: 次の問題
